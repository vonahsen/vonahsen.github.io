Replacing a cheap fan remote with an SDR setup

When my wife and I replaced our ceiling fans, most manufacturers have moved to built-in LED lights and replacing pull chains with wireless remotes. I had previously been using smart bulbs to tie into HomeAssistant, but built-in LEDs means I can't use smart bulbs or add an intermediate smart dongle of some type.

Surely, I thought, these use extremely common radios, and someone has already figured this out. One fan's remote had an FCC sticker, 2A9T3-RF601A. Looking up this ID on either FCC Report or FCCID.io, shows that it uses the very common 433.92 frequency.

Grabbing my Flipper Zero, I was able to record both the "light on" and "light off" signals, and after replaying the saved .sub file, the lights responded appropriately. This is what the Flipper .sub file looks like:
